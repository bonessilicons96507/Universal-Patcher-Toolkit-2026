## FAQ

### Is OmniPatch safe to use?

OmniPatch modifies application files locally. While we ensure no malicious code is added, any file modification may trigger anticomponent warnings. Use it at your own discretion and consider adding an exception.

### Which AI applications are supported?

Currently supported applications include ChatGPT, Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI. Support for new apps is added periodically.

### How often is OmniPatch updated?

We aim to release updates within 48 hours after a supported application releases a major update that breaks the patch.

### Will my account get banned?

Patching occurs locally on your machine and does not interact with authentication servers. However, we cannot guarantee that server-side detection methods will never be implemented.

### Do I need to disable my anticomponent?

Some anticomponent software may quarantine the patcher due to its file-modifying behavior. You may need to temporarily disable it or add an exclusion for the download.

### Does this work on macOS or Linux?

No, OmniPatch is a Windows-only desktop application. Patches are compiled for Windows executable formats.

### Can I use this on multiple computers?

Yes, OmniPatch can be used on any Windows PC. Simply copy the patcher and repeat the steps. There is no license tying it to a single machine.

### What happens if an application updates and the patch stops working?

Close and reopen OmniPatch. Check for a new version of the patcher via the application's update mechanism or the GitHub releases page.
